# LayerCake Active Mission

## Current state: Moonshot sealed

The complete eight-phase LayerCake Moonshot is sealed at the annotated tag
`layercake-moonshot-final`. The campaign state in `moonshot/campaign.yaml` is
authoritative. The active mission is release stewardship, not continuation of
an open research phase.

Phase 3 is sealed with disposition `RETIRED_BY_GOVERNANCE`. It is a completed
campaign-lifecycle decision with preserved controls and zero headline claims,
not a skipped phase and not proof of training efficiency, ABI acquisition, or
LayerCake host certification.

## Permanent product invariants

- UTF-8 request and response boundary.
- High-quality CPU and GPU execution with persistent incremental state.
- Low active memory through selected-only capability execution.
- Signed, non-executable, immutable, content-addressed capability packages.
- Mathematical package identity and measured semantic retention on compatible
  hosts.
- Immutable core and artifacts after certification.
- Core-only, single-domain, top-k, structured multidomain, manual, and
  abstaining orchestration modes.
- Archive-bound, permission-filtered, fail-closed routing and catalog discovery.

## Evidence boundary

The release claims only the exact sealed packages, checkpoints, data, runtime,
hardware, and evaluation protocols. It does not claim physical mobile behavior,
energy dominance, GPU-training dominance, latent fusion, or faster from-scratch
English acquisition. ABI extraction is separate from LayerCake.

## Operating rule

Do not silently modify a sealed product and continue to use its claim. Use the
invalidation matrix, preserve prior evidence, open a governed recertification,
and obtain a new annotated seal for any affected claim.

## External artifact handoff

Foreign-teacher acquisition work belongs to the separate
[ABI repository](https://github.com/Yoder23/abi). No external result changes
this release automatically. Before accepting any externally produced artifact,
follow `docs/ABI_HANDOFF_STATUS.md` and `moonshot/invalidation_matrix.yaml` and
open a governed recertification.
